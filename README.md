<h2 align="center">⚡ ・゜゜・　゜　ABOUT THE BOT　゜　・゜゜・ ⚡</h2>

<p align="center">
  <img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=18&duration=3000&pause=600&color=A78BFA&center=true&vCenter=true&width=720&lines=A+Telegram+bot+forged+in+the+fires+of+the+Mangekyō.;Removes+backgrounds+like+a+Susano%E2%80%99o+slash.;Uploads+images+to+permanent+links+in+seconds.;Lets+anyone+spawn+their+OWN+clone+%E2%80%94+the+Madara+Network." />
</p>

> **Madara Image Bot** is a high-performance Telegram bot built with `python-telegram-bot 22.7`.
> It removes backgrounds with **remove.bg**, hosts uploads on **imgbb**, scans every photo for NSFW with **NudeNet**, and most importantly — lets **any user clone the bot** with a single command and customize their own copy.
>
> One master 👑 (you) controls the entire network.

<h2 align="center">🏯 ・゜゜・　゜　ARCHITECTURE　゜　・゜゜・ 🏯</h2>

\`\`\`
┌──────────────────────────────────────────────────────────────┐
│                    👑  SUPREME  MASTER  👑                    │
│                  (controls the whole network)                 │
└────────────┬─────────────────────────────────┬───────────────┘
             │                                 │
   ┌─────────▼────────┐               ┌────────▼─────────┐
   │   MAIN  BOT      │               │   /broadcast     │
   │   @IMAGE_TO_..   │  ←──fans out──┤   propagates to  │
   │                  │               │   ALL CLONES     │
   └──────┬───────────┘               └──────────────────┘
          │  /clone <token>
          ▼
   ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
   │   CLONE BOT #1   │  │   CLONE BOT #2   │  │   CLONE BOT #N   │
   │   own owner      │  │   own owner      │  │   own owner      │
   │   own API keys   │  │   own API keys   │  │   own API keys   │
   │   own users.db   │  │   own users.db   │  │   own users.db   │
   └──────────────────┘  └──────────────────┘  └──────────────────┘
\`\`\`

All clones run inside **one asyncio loop** — single process, low overhead, instant boot.
State persists to `clones.json` so the entire network auto-resumes after restart.
