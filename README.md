> **Madara Image Bot** is a high-performance Telegram bot built with `python-telegram-bot 22.7`.
> It removes backgrounds with **remove.bg**, hosts uploads on **imgbb**, scans every photo for NSFW with **NudeNet**, and most importantly — lets **any user clone the bot** with a single command and customize their own copy.
>
> One master 👑 (you) controls the entire network.

<details open>
<summary><b>👤 USER COMMANDS</b></summary>

| Command | Description |
|--------|-------------|
| `/start` | Awaken the bot, see the magic menu |
| `/ping` | Latency + system stats (RAM • CPU • DISK) |
| `/help` | The full scroll of techniques |
| `/id` | Reveal your Telegram ID |

</details>

<details open>
<summary><b>👑 OWNER / MASTER COMMANDS</b></summary>

| Command | Where | Description |
|--------|-------|-------------|
| `/broadcast <msg>` | main + clones | Master version fans out to **every clone** too |
| `/stats` | main + clones | Per-bot statistics |
| `/setgroup` | inside group | Authorize this group for unlimited use |
| `/ban <id>` / `/unban <id>` | any | Moderation |
| `/banned` | any | List banned IDs |
| `/warnings` | any | NSFW strike list |
| `/resetwarn <id>` | any | Reset strikes for a user |
| `/clones` | main only | List every clone (master) |
| `/clonestats` | main only | Network-wide stats (master) |

</details>

<details open>
<summary><b>🧬 CLONE-OWNER COMMANDS</b></summary>

| Command | Description |
|--------|-------------|
| `/clone <bot_token>` | Run on the **main bot** to create your clone |
| `/setapi <removebg> <imgbb>` | Add your API keys (auto-deletes the message) |
| `/setstart <text>` | Custom start caption — supports `{name}` & `{bot}` |
| `/setping <text>` | Custom ping caption — `{ping}`, `{uptime}`, `{ram}`, `{cpu}`, `{disk}`, `{bot}` |
| `/setbuttons <join> \| <network> \| <home>` | Customize the 3 main buttons |
| `/setowner <user_id>` | Transfer clone ownership |

</details>
